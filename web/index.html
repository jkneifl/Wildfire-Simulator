Browser build of the Wildfire testbed simulator: 256 × 256 cells, 240-step day, 33 × 33 agent window. The rules and randomness match the Python reference bit for bit, so seed 0 here is the same world as python -m wildfire.app.play --seed 0. Futures (K) runs 16 forked futures for 100 steps and shades each cell by how often it burns. Save and load keep one slot in this browser.
